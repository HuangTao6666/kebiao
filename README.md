# 我的课表（手机版）

一个为手机设计的课表应用（PWA，可添加到主屏幕、可离线使用），数据来自你导出的
教务系统课表 Excel（`课表详情.xlsx` 已内置）。

## 功能

- **自动定位本周**：打开即显示本周课表，并按当天日期自动更新，无需手动切换。
- **今天高亮**：周课表中今天的列自动高亮，底部「今日」页列出今天的全部课程。
- **周次切换**：左右箭头翻看任意一周，可一键「回到本周」。
- **课程详情**：点击任意课程查看教师、教室、周次、节次、性质等。
- **自动识别导入**：随时导入新的教务系统 Excel（.xlsx），或从 Excel 复制后直接粘贴。
- **离线可用**：添加到主屏幕后，即使断网也能打开（首次加载后）。

## 重要：先设置学期开始日期

首页显示的「第几周」是根据**第 1 周的周一**计算出来的。应用默认设置为
`2026-09-07`（一个周一），请按你的实际情况修改：

1. 打开应用 → 底部「设置」。
2. 在「学期开始（第 1 周的周一）」选择正确日期 → 保存。

即使周次数字暂时不对，**首页仍然会自动显示“包含今天的这一周”**，只是左上角的
“第 X 周”标签需要正确日期才准确。

## 如何在手机上使用

### 方法一（推荐）：免费托管，长期稳定

把整个 `课表App` 文件夹上传到任意免费静态托管（三者任选其一，都需要注册一个账号）：

- **GitHub Pages**：新建仓库 → 上传本文件夹内容 → Settings → Pages → 选择 main
  分支 → 得到 `https://你的用户名.github.io/仓库名/` 网址。
- **Gitee Pages**（国内访问快）：同上，发布后得到 gitee.io 网址。
- **Vercel / Netlify**：把文件夹拖进网站即可发布。

手机浏览器打开该网址 → 添加到主屏幕 → 完成。

### 方法二：电脑一键局域网（手机和电脑连同一个 Wi-Fi）

1. 双击本文件夹里的 `start_server.bat`。
2. 窗口里会显示一个 `http://192.168.x.x:8080` 地址。
3. 手机浏览器打开这个地址，再「添加到主屏幕」。
4. 电脑关机或断开 Wi-Fi 后无法访问，所以长期使用建议用方法一。

### 方法三：直接发文件到手机

把整个 `课表App` 文件夹发到手机（微信/QQ 或数据线）。手机上找到 `index.html`，
用浏览器打开即可使用。此方式不支持「安装到主屏幕」和离线缓存，仅适合临时查看。

## 添加到主屏幕（像 App 一样）

- **Android**：Chrome 打开 → 右上角菜单 ⋮ → **安装应用 / 添加到主屏幕**。
- **iPhone**：Safari 打开 → 底部分享按钮 → **添加到主屏幕**。

## 更新课表

- 最简单：应用内「设置 → 导入 Excel / CSV」，选择新的导出文件，全自动识别替换。
- 或者：把新 Excel 放到 `tools` 目录，运行
  `python tools/convert_excel.py 你的课表.xlsx -o data.js`，
  重新生成内置数据后再把文件夹重新发布一次。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` / `styles.css` / `app.js` | 应用本体 |
| `parser.js` | 课表 Excel / 文本解析器（内置，不依赖网络） |
| `data.js` | 内置课表数据（由你的 `课表详情.xlsx` 生成） |
| `sw.js` / `manifest.webmanifest` / `icons` | PWA 安装与离线支持 |
| `tools/convert_excel.py` | Excel → data.js 转换工具 |
| `start_server.bat` | 电脑上一键启动局域网服务 |

## 隐私

所有课表数据只保存在你手机浏览器的本地存储中，不会上传到任何服务器。
